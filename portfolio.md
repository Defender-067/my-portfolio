## Lab 7 Reflection – Merge Conflicts

### 1. Why did the conflict occur?
- Both branches edited the same lines under `## Skills` at the same time.

### 2. What would have prevented this conflict?
- Pulling the latest changes before editing, or using separate branches for different tasks.

### 3. How do you avoid conflicts on multiple devices?
- Always run `git pull` before you start working on a device.
- Always run `git push` when you finish working.

### 4. What was the most challenging part?
- Cleaning up the conflict markers (`<<<<<<<`, `=======`, `>>>>>>>`) without deleting any good code.

### 5. How did Git identify the conflict?
- Git added conflict markers directly inside `portfolio.md` and named the file in the terminal.
